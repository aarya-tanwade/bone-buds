# Bone Buds hardware

## Current design: Rev B (compact custom-IC wearable)

See [Rev B hardware](./compact_v2/README.md).

Rev B is a **design-stage**, multi-board architecture using a compact controller PCB and
left/right audio PCBs. The matching wearable CAD is in the mechanical directory.
These boards are **not claimed to be electrically bench-tested, RF-qualified,
medically validated, or production-certified**. Verify footprints, electrical
performance, physical fit, charging safety and acoustics before fabrication/use.

The original development-board carrier (Rev A/V1) has been retained in a local
backup outside this Git repository rather than deleted.
